2. Restate the problem 
- integers array is given , need to return the total number of subarrays whose sum equals to k

3. Discuss Possible Approaches 

- I can find all the possible subarrays , store it in list , then traverse through the list and subarray whose sum is equal to K , count it and return ->O(n^2)
- I can also use the prefix sum ,

```java
import java.util.HashMap;

class solution {
    public int subarraySum(int[] nums, int k) {
        int n = nums.length;
        int count=0;
        Map<Integer, Integer> map = new HashMap<>();
        map.put(0,1);
        int prefixSum=0;
        for(int i=0;i<n;i++){
            prefixSum += nums[i];
            
            if(map.containsKey(prefixSum-k)) {
                count += map.get(prefixSum-k);
            }
            if(map.containsKey(prefixSum)){
                map.put(prefixSum, map.get(prefixSum)+1);
            }else{
                map.put(prefixSum,1);
            }
        }
        return count;
    }
}
```
